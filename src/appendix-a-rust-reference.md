# Rust 빠른 참조

본문을 읽다가 문법이 기억나지 않을 때 돌아볼 항목만 모았다.

| 문법 | 뜻 | 자주 쓰는 곳 |
|---|---|---|
| `String` | 문자열 데이터를 소유하는 타입 | 구조체 필드, 반환값 |
| `&str` | 문자열을 빌려 보는 참조 | 읽기 전용 함수 인자 |
| `Option<T>` | 값이 있거나 없음 | 조회 결과, 선택 설정 |
| `Result<T, E>` | 성공값 또는 오류 | 파싱, 검증, I/O |
| `Vec<T>` | 순서가 있는 가변 길이 목록 | 블록, 트랜잭션 목록 |
| `HashMap<K, V>` | 키로 값을 찾는 컬렉션 | 주소별 잔액 |
| `struct` | 여러 필드를 묶은 데이터 타입 | 블록, 트랜잭션, 설정 |
| `enum` | 가능한 상태를 제한한 타입 | 처리 상태, 오류 종류 |
| `impl` | 타입의 메서드와 연관 함수 | 생성·검증 로직 |
| `trait` | 여러 타입이 공유할 동작 계약 | 저장소, 서명기, RPC 경계 |

## 소유권을 고르는 기준

- 함수가 값만 읽으면 `&T`, `&str`, `&[u8]`부터 검토한다.
- 함수가 값을 수정하면 `&mut T`를 쓴다.
- 구조체가 값을 보관해야 하면 `String`, `Vec<T>`처럼 소유한 타입을 쓴다.
- 독립된 복사본이 정말 필요할 때만 `clone()`을 쓴다.

## 실패 처리

외부 입력과 I/O 실패는 `Result`로 돌려준다. `?`는 `Err`를 호출자에게 조기 반환한다. 값이 없을 수 있는 조회는 `Option`으로 표현한다. `unwrap()`과 `expect()`는 테스트나 코드가 보장하는 내부 불변식에만 제한한다.

## 비동기 코드

Rust의 `async fn`은 Future를 만든다. Future는 Tokio 같은 런타임이 실행해야 진행된다. 온체인 프로그램보다 RPC 클라이언트, 인덱서, 노드처럼 오프체인 네트워크 작업에서 주로 만난다.
